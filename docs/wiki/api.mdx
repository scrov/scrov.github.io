# API Specification

The machine-readable source is [`openapi.yaml`](../../openapi.yaml).

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/v1/health` | Service health |
| GET | `/api/v1/profile` | CV/profile data |
| GET | `/api/v1/projects` | Portfolio projects |
| GET | `/api/v1/wiki` | Wiki index |
| GET | `/api/v1/wiki/{slug}` | Wiki entry |
| POST | `/api/v1/contact` | Contact submission |

## Resource shape

```json
{
  "data": {
    "id": "project-001",
    "type": "portfolio-project",
    "attributes": {
      "title": "Realtime Web Platform",
      "status": "active"
    }
  }
}
```
