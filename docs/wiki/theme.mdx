# Black-Green Theme

## Visual contract

```css
:root {
  --bg: #050705;
  --panel: #0a0d0a;
  --text: #b8c7b8;
  --muted: #6e7d6e;
  --green: #39ff88;
  --green-soft: #8af7b2;
  --border: #18301f;
}

body {
  background: var(--bg);
  color: var(--text);
  font-family: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
}

a {
  color: var(--green-soft);
}

code,
pre {
  font-family: inherit;
}
```

The GitHub repository view remains GitHub-controlled, so the black-green presentation belongs to the rendered `scrov.github.io` site. The README source stays portable and the site applies the visual shell.
