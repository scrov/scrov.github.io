# Black-green presentation contract

The README source stays renderer-portable. The visual treatment belongs to the Astro site layer.

Recommended visual system:

- near-black canvas
- terminal-green accent
- muted gray-green body text
- monospace headings and code
- 1px low-contrast borders
- restrained glow only on interactive states
- no gradient-heavy dashboard styling
- responsive single-column reading flow with an optional documentation rail
